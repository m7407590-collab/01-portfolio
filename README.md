# Personal Portfolio — Level 1, Task 1

A single-page personal portfolio built with plain HTML and CSS.

## Live sections

- **Header** — name/logo and a sticky nav bar
- **Hero** — short intro line
- **About** — photo, short bio
- **Skills** — languages, frameworks, tools, and practices grouped into cards
- **Resume** — a download button for a résumé PDF
- **Contact** — email, phone, and social links
- **Footer** — copyright line and back-to-top link

## Files

01-portfolio/
├── index.html
├── style.css
└── README.md

## How to use

1. Open "index.html" in a browser — no build step or dependencies needed.
2. Replace the placeholder name, photo, bio and links with your own.
3. Drop your actual resume PDF.
4. Update the social links in the contact section to your own profiles.

## Built with

- HTML5
- CSS3 (custom properties,CSS Grid,Flexbox)
- Google Fonts:Space Grotesk,Inter,JetBrains Mono

## Notes

Fully responsive down to mobile widths,with a sticky header and a subtle
blinking cursor accent in the logo.No JavaScript framework—just a two line
script to auto-update the copyright year.
